# Roadmap

## Milestone 0 — Simulation foundation
- [x] Define scope and requirements.
- [x] Implement burst generation, noise channel, detectors, Monte Carlo sweep.
- [x] Add tests and CI configuration.
- [x] Run locally and generate plots/metrics.

## Milestone 1 — Stronger experiments
- [ ] Add parameter configuration files.
- [ ] Calibrate thresholds against a stated false-alarm target.
- [ ] Add Monte Carlo confidence intervals and sensitivity analysis.
- [ ] Write a report explaining assumptions and results.

## Milestone 2 — Sensor and circuit selection
- [ ] Compare integrated demodulating receiver and photodiode architectures.
- [ ] Choose compatible modulation frequency and receiver bandwidth.
- [ ] Create a schematic and power budget based on datasheets.
- [ ] Review optical and electrical safety.

## Milestone 3 — Bench prototype
- [ ] Build a safely directed low-power test setup.
- [ ] Capture actual receiver samples and compare them with simulation.
- [ ] Record equipment, settings, setup photos, and measurement uncertainty.

## Milestone 4 — Demonstration
- [ ] Publish a repeatable demo.
- [ ] Report physical results only after documented repeatable measurements.
