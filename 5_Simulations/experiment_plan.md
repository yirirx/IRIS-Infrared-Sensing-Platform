# SIM-002 — Independently Calibrated Detection Probability

## Research question
At a fixed false-alarm operating point, how does detection probability change with SNR for energy detection and matched-filter detection of a known modulated burst?

## Model and SNR convention
- The reference is the deterministic on/off-keyed sinusoidal burst generated by `make_burst()`.
- Noise is zero-mean, unit-variance additive white Gaussian noise (AWGN).
- `SNR_dB = 10 log10(mean(clean_signal²) / noise_variance)`, with signal power averaged across the entire observation window.
- The clean reference is amplitude-scaled for each SNR; the noise variance remains fixed.
- This is an abstract signal-processing model. It does not model optical power, distance, a real photodiode, sunlight, or a physical receiver.

## Procedure
1. Generate independent noise-only calibration windows.
2. Set each detector's threshold to the empirical upper quantile corresponding to the target false-alarm rate.
3. Evaluate the threshold on a separate noise-only validation set.
4. Evaluate signal-present detection probability over an SNR sweep.
5. Report Wilson 95% confidence intervals for detection and validated false-alarm rates.
6. Save seed, thresholds, trial counts, and model label in `metrics.csv`.

## Reproducibility
Run `python -m iris_sim --output 5_Simulations/results --trials 1000 --seed 20261014`. The CLI uses a default target false-alarm rate of 5%, 5,000 calibration windows, and 5,000 independent validation windows.

## Interpretation rules
- Finite-sample false-alarm rate will not equal the target exactly.
- Confidence intervals describe Monte Carlo sampling uncertainty under this model, not uncertainty in a real optical system.
- Compare detector performance only under the stated assumptions.
- Do not infer physical detection range or claim hardware validation from these results.
